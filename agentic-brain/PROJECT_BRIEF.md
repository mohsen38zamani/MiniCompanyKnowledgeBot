# Mini Company Knowledge Bot

## Project Goal
Build a Laravel-based knowledge bot that answers user questions using only local company documents.

## MVP Definition
- Laravel 10 backend (PHP 8.1 compatible)
- Documents stored in `docs/`
- Simple UI and API for asking questions
- Deterministic retrieval from local docs
- Grounded answers without external hallucinated content

## Constraints
- Keep architecture simple and maintainable
- Separate retrieval logic from answer generation logic
- Use meaningful, small commits through all phases
